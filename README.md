# Recipe Finder

A recipe discovery app with meal planning and shopping list generation. Search recipes by ingredients, cuisine, or dietary restrictions.

## Getting Started

```bash
npm install
npm run dev
```

## Environment Variables

Create a `.env` file to connect to the Spoonacular API:

```bash
VITE_SPOONACULAR_KEY=your_key_here
```

When no API key is supplied, the app falls back to curated sample recipes.
